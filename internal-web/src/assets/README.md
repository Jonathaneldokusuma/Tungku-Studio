# Asset Map

Folder ini dipakai sebagai sumber asset UI agar implementasi tidak menebak bentuk logo, icon, atau mockup.

## brand

Taruh asset identitas brand di sini.

- `logo.svg` atau `logo.png`: logo utama Tungku Studio.
- `brand-mark.svg` atau `brand-mark.png`: icon kecil untuk sidebar/topbar.

## icons

Taruh icon set dari Figma di sini.

- `figma-icons.svg`: icon sheet export dari Figma.
- Untuk hasil paling akurat, boleh juga isi icon satuan seperti `dashboard.svg`, `booking.svg`, `package.svg`, dan seterusnya.

## mockups

Taruh export mockup referensi dari Figma di sini. File di folder ini hanya untuk referensi visual, bukan untuk ditempel sebagai working page.

- `manager-dashboard.svg/png`
- `management-paket.svg/png`
- `manager-crm.svg/png`
- `operator-tasks.svg/png`
- `client-booking.svg/png`

## screens

Taruh asset gambar yang memang dipakai di screen, misalnya avatar, empty state, cover, atau thumbnail.
